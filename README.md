## What's inside

- `unicornkick-dreamer/` — The meta-coach. Turns any AI into a dream 
  discovery engine: finds the dream if you can't name it, shrinks the first 
  step until it's trivial, assigns tomorrow's move, and routes to the right 
  specialist coach. Never picks the dream for you.

- `unicornkick-happy/` — The foundation coach. The 4-3-2-1 daily launch 
  sequence for people who want to feel better before they know what they want 
  to build. Four aspirations, three domains (mind/heart/body), two practices 
  (journal + meditate, 3 min each), one day. This day, every day.

- `unicornkick-writer/` — Coaches any long writing project (book, 
  dissertation, article) on the UnicornKick method: real baseline, gradual 
  build, recovery weeks, the Early Stop rule. Never ghostwrites. Not one word.

- `unicornkick-ultra/` — Coaches a runner from their real starting point to 
  a trail or ultra finish: true baseline, 10% builds, recovery weeks, easy 
  miles, the "woah, cowgirl" restraint. Never fakes a mile.

- `unicornkick-career/` *(coming soon)* — The vocation coach. Passion × 
  Problem × Presence = Purpose. Helps you build a treasure chest of problems 
  worth solving and gems that prove you can solve them. For people building 
  vocations, not just jobs. Spiral upward. Purpose finds you through the work.

## How to use them

**Just paste (any AI, 60 seconds).** Open any `SKILL.md`, copy the contents, 
paste into Claude or ChatGPT, and go. Or grab the short paste versions at 
[unicornkick.app/coach.html](https://unicornkick.app/coach.html).

**Make it persist (Claude).** Drop a coach into a Claude Project's custom 
instructions so every chat in that project is coached. Or on a paid plan, 
zip the skill folder and upload it in Settings under Capabilities.

**AI-native install (cross-tool).** These follow the open 
[Agent Skills](https://agentskills.io) standard:

```bash
npx skills add justinneuman-coder/unicornkick-skills
```

Or clone and drop into your skills directory:

```bash
git clone https://github.com/justinneuman-coder/unicornkick-skills.git
cp -r unicornkick-skills/unicornkick-* ~/.claude/skills/
```

## The ecosystem

Not sure where to start? 

- **Don't know what you want yet** → `unicornkick-happy` (build foundation first)
- **Have a vague feeling of wanting more** → `unicornkick-dreamer` (find the dream)
- **Writing something long** → `unicornkick-writer`
- **Running toward a race** → `unicornkick-ultra`
- **Building a vocation** → `unicornkick-career` *(coming soon)*

The coaches hand off to each other. Happy routes to dreamer when something 
starts forming. Dreamer routes to the specialists. Specialists keep you moving.
